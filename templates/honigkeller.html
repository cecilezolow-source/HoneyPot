Erwischt! Du steckst im Honigtopf.

Dieser „Admin-Bereich“ war nie echt. Er ist ein Honeypot: ein Köder, der nur dazu da ist, Angreifer:innen anzulocken und zu beobachten. Genau wie Bären, die den Honig nicht liegen lassen können.

honeypot.log 
[ALARM] Zugriff auf Köder-Endpunkt /honigkeller
  benutzer    = {{ erwischt.username }}
  passwort    = {{ '•' * erwischt.pw_laenge }} ({{ erwischt.pw_laenge }} Zeichen)
  ip          = {{ erwischt.ip }}
  user_agent  = {{ erwischt.user_agent }}
  quelle      = robots.txt gelesen? Sehr wahrscheinlich.
  aktion      = Schwarm alarmiert
Keine Sorge: In dieser Übung wird nichts gespeichert. Ein echter Honeypot würde diese Daten aber jetzt protokollieren und das Security-Team alarmieren.

Was lernen wir daraus?

  • robots.txt ist kein Schutz, sondern eher eine Schatzkarte für Angreifer:innen.
  • Verteidiger:innen nutzen genau das aus und legen gezielt Köder aus.
  • Der echte Schatz liegt woanders … vielleicht in einer Tabelle, die die App nie benutzt?
